Wiki Memo — Wikipedia風スマホメモPWA

1. ZIPを解凍し、中のファイルをGitHubリポジトリのルートへアップロードしてください。
2. GitHubの Settings → Pages → Deploy from a branch → main / (root) を選択します。
3. 公開されたHTTPSのURLをスマホで開き、ブラウザの「ホーム画面に追加」を選択します。

記事は各端末のブラウザ内のIndexedDBに保存されます。GitHubに記事内容はアップロードされません。
設定画面からJSONバックアップを定期的に保存してください。
Photo Memoとは別アプリです。既存のPhoto Memoを上書きしないでください。
